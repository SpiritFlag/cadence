## 1. 범위

제안한 패키지가 그래프에 박스로 보이고, 박스끼리 순위대로 이어진다.

### 1.1 패키지를 그래프에 박스로 — #17

- 무엇을: 지금은 패키지가 오른쪽 카드에만 있고 그래프에는 이슈 노드와 막음 선뿐이다 → 마지막 제안이 `ok`면 패키지마다 그래프에 박스가 생기고 머리에 `순위 · 이름`이 붙는다. 그 패키지의 열린 이슈 노드가 박스 안에 놓이고, 박스를 끌면 안의 노드도 같이 움직인다. 패키지에 안 든 이슈(대기 · hold · 진행 중)는 박스 밖에 남는다. 박스 안 막음 선과 박스를 넘는 막음 선은 지금처럼 그린다. 제안이 없거나 `none`이면 박스가 없다(지금과 같다). 제안 뒤 이슈가 닫혀 열린 이슈가 0개인 패키지는 박스를 그리지 않는다.
- 어떻게: 화면 층만. 레이아웃이 제안도 받아 dagre 박스(compound) 배치를 쓰고, 박스 노드 컴포넌트를 더한다. 서버 · DB · API는 안 건드린다. 제안이 바뀌어도 다시 배치한다.
- 끝(SC-1): Fishing 레포에서 [제안] 뒤 패키지마다 박스가 생기고 그 패키지 이슈가 박스 안에, 패키지에 안 든 이슈는 박스 밖에 있으며 막음 선은 그대로 보인다 — `bun run check` + 육안 `bun run dev`
- 왜 이렇게: 카드에만 있는 묶음을 그래프 위치로도 보이게 한다. 박스 좌표를 손으로 계산하면 dagre 배치와 겹쳐 버렸다. `docs/SPEC.md` 화면 절(노드 · 다시 배치하는 조건)을 바꾼다.

### 1.2 박스끼리 순위 선 — #17

- 무엇을: 순위가 이어지는 박스끼리 선을 긋는다(1 → 2 → 3 …, 카드 순위 원과 같은 파랑 실선). 이 선은 표시용이라 막음 선으로 저장하지 않고 상세 칩 · 후보 순서 · 다음 제안에 들어가지 않는다. 가운데 박스가 빠지면(열린 이슈 0개) 앞뒤 박스끼리 잇는다. 박스는 순위대로 위에서 아래로 놓인다.
- 어떻게: 배치에서는 앞 박스 이슈 → 뒤 박스 이슈를 숨은 선으로 걸어 층을 잡고, 화면에는 박스 노드 사이 선 하나만 그린다.
- 끝(SC-2): 같은 화면에서 박스가 순위대로 위→아래로 놓이고 박스끼리 파랑 선이 이어지며, 새로고침해도 `/api/deps` 선 수가 늘지 않는다 — `bun run check` + 육안 `bun run dev`
- 왜 이렇게: 실측에서 dagre는 박스 노드끼리 선을 걸면 배치 중 예외가 났고, 박스 안 노드끼리 숨은 선은 박스 순서를 잡았다. 막음 선으로 저장하면 표시가 데이터를 오염시켜 버렸다.
