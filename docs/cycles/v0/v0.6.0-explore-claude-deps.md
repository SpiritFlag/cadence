## 1. 범위

claude가 고른 레포의 의존 선을 긋고, 사용자 선은 사용자가 승인해야만 바뀐다.

### 1.1 claude가 선을 긋고 갈아끼운다 — #11

- 무엇을: 지금은 선을 사용자만 긋고 선에 출처가 없다 → 헤더 [제안] 옆 [그래프 생성]을 누르면 claude(opus)가 고른 레포의 열린 이슈 전부(hold · 진행 중 포함, 제목 · 본문 · 라벨)와 기존 선을 읽고 선마다 막는 쪽 · 막히는 쪽 · 이유를 낸다. 선은 본문에 순서가 적혔거나 층의 선후가 분명한 관계이고, 함께 정한다 · 같은 계열 같은 관련은 선이 아니다. 선에 출처(사용자 | claude)가 붙고 기존 선은 사용자 선이다. 그래프에서 claude 선은 보라 점선, 사용자 선은 회색 실선. 상세 칩에 claude 표시와 이유 툴팁. 다시 생성하면 그 레포의 claude 선을 전부 지우고 새로 넣는다. 사용자 선과 같은 claude 선은 넣지 않는다. 기존 claude 선을 사용자가 손으로 다시 그으면 사용자 선이 된다. 넣다가 순환을 만드는 claude 선은 버리고 경고(`#3 → #5 · 순환이라 안 그음`). 생성 결과 한 줄(`claude 선 n · 순환이라 버림 n · 비용`)이 그래프 칸 위에 뜨고 sqlite에 남는다. 생성 중에는 [제안] · [그래프 생성] · 새로고침이 꺼지고 로그 칸에 단계가 흐른다. 후보 순서 · 제안은 두 출처 선을 똑같이 쓴다.
- 어떻게: DB는 선에 출처 · 이유를 더하고 생성 결과를 저장한다. 서버는 그래프 생성 모듈이 기존 claude 호출(스키마 강제)을 재사용해 받고, 거르고, 순환을 검사해 교체한다. 화면은 헤더 버튼 · 선 스타일 · 결과 줄.
- 끝(SC-1): [그래프 생성]을 누르면 Fishing 레포에 claude 선이 점선으로 그어지고, 다시 누르면 claude 선만 바뀌고 사용자 선은 그대로이며, 순환을 만드는 선은 저장되지 않고 경고로 뜬다 — `bun test`(교체 · 사용자 선 보존 · 순환 버림) + 육안 `bun run dev`
- 왜 이렇게: 출처를 선 테이블의 열로 두면 후보 순서 · 제안이 선을 합쳐 읽지 않아도 된다. 전부 갈아끼우면 claude 판단이 한 번에 일관되고, 사용자가 지운 것은 1.3이 따로 기억한다. `docs/SPEC.md` 의존 선 절(사용자만 긋는다)을 바꾼다.

### 1.2 사용자 선을 지우자는 제안 — #11

- 무엇을: 같은 생성에서 claude가 사용자 선마다 `유지` · `지움` · `뒤집음`을 판정한다. 유지는 보이지 않는다. 지움 · 뒤집음만 결과 줄 밑 제안 목록에 이유와 [승인] [거절]로 뜬다. 승인하면 지우고, 뒤집음은 반대 선을 함께 사용자 선으로 긋는다. 거절하면 제안만 사라지고 기억하지 않는다. 제안에 마우스를 올리면 두 이슈가 강조된다. 다시 생성하면 남은 제안은 새 판정으로 바뀐다. 이미 없는 선의 제안은 승인해도 아무 일 없이 사라진다. 코드는 승인 없이 사용자 선을 지우지 않는다.
- 어떻게: 생성 스키마에 사용자 선 판정을 더하고 지움 · 뒤집음만 제안으로 저장한다. 승인 · 거절 API, 그래프 칸의 제안 목록.
- 끝(SC-2): 일부러 틀리게 그은 사용자 선이 있으면 [그래프 생성] 뒤 지움이나 뒤집음 제안이 이유와 함께 뜨고, 승인하면 지워지거나 뒤집히고 거절하면 그대로다 — `bun test`(승인 없이 안 지워짐 · 뒤집음 짝 적용 · 사라진 선 제안) + 육안(Fishing에 틀린 선을 손으로 긋고 생성)
- 왜 이렇게: 지움과 긋기를 따로 승인하면 선이 빈 중간 상태가 생겨 뒤집음을 한 동작으로 묶는다. 거절을 기억하면 본문이 바뀌어도 다시 묻지 못한다.

### 1.3 지운 claude 선을 기억한다 — #11

- 무엇을: 사용자가 claude 선을 지우면 그 선을 기억한다(사용자 선 삭제 · 재생성 교체는 기억하지 않는다). 다음 생성은 claude에게 지운 선 목록을 주고(맞다고 보면 그대로 내게 한다), claude가 그 선을 다시 내면 긋지 않고 `다시 긋자 · 이유` 제안으로 띄운다. 승인하면 사용자 선으로 긋고 기억에서 뺀다. 거절하면 기억이 남는다. 기억된 선을 손으로 그어도 사용자 선이 되고 기억에서 빠진다. 다시 긋자는 제안도 순환 검사를 받아 순환이면 경고로 간다.
- 어떻게: DB에 지운 선 기억을 두고, 선 삭제에서 출처가 claude면 기록하고, 생성 결과를 기억과 대조해 제안으로 돌린다.
- 끝(SC-3): claude 선을 지우고 다시 생성해도 그 선은 그래프에 생기지 않고, claude가 다시 내면 이유와 함께 제안으로 뜨며 승인하면 사용자 선으로 그어진다 — `bun test`(claude 선 삭제만 기억 · 기억된 선은 제안 · 승인하면 기억 해제) + 육안
- 왜 이렇게: 조용히 버리지 않고 제안으로 올리면 이슈가 바뀌어 맞아진 선을 놓치지 않는다. 사용자가 승인한 선은 사용자 선이라는 규칙을 1.2와 같이 쓴다.

제외: 그래프에서 선 지우기(상세 패널 ×만). 받는 중 로그를 경과 시간으로도 내기.
